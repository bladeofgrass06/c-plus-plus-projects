To compile and run the file:

    1. Make sure that you have a C++ compiler like g++ or clang installed
    2. Open your terminal
    3. Navigate to the folder where it is located.

        Ex: cd [Folder 1]/[Folder 2]/[Folder 3]/Programming_Assignment_1 (Mac and Windows)
    
    4. Compile source code using any compiler

        Ex 1: g++ programming_assignment_1.cpp -o program
        Ex 2: clang++ programming_assignment_1.cpp -o program
    
    5. Run the compiled code

        Ex: ./program
